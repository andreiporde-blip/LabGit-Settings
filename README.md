# LabGit-Settings
Лабораторная работа по настройке репозитория

## Описание проекта
**Название:** LabGit-Settings
**Назначение:** Учебный проект для освоения настройки репозитория GitHub.

## Структура каталогов
- `src/` — исходный код
- `docs/` — документация
- `tests/` — тестовые материалы
- `assets/` — вспомогательные материалы

## Исключаемые файлы
Из отслеживания исключены: каталоги `build/`, `logs/`, `temp/`, файлы `.env`, `*.tmp`, `*.log` и другие (см. `.gitignore`)..
